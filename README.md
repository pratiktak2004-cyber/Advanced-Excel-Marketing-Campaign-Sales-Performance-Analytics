# Advanced-Excel-Marketing-Campaign-Sales-Performance-Analytics

Engineered an Advanced Excel commercial analytics model to ingest raw sales logs, perform multi-level data aggregation, and evaluate multi-channel marketing performance. Features relational data organization, complex PivotTable grouping hierarchies, and interactive reporting to analyze customer acquisition (New vs. Existing) and campaign ROI.

## Workbook Architecture & Sheet Mapping

| Sheet Name | Role & Contents |
| :--- | :--- |
| **`Sheet1`** | Executive Pivot summary featuring multi-level grouping (Channel and Customer Type). |
| **`Raw_Data`** | Primary transaction ledger capturing transaction IDs, campaign tags, channels, and revenue metrics. |
| **`Channel`** | Dedicated reporting view summarizing Total Sales by Marketing Channel (`Email`, `Instagram`, `Web Banner`). |
| **`Campaign`** | Comparative performance view tracking revenue generation across promotional campaigns (`A` vs. `B`). |

---

## Advanced Excel Technical Features
* **Multi-Level PivotTable Grouping:** Nested row hierarchies breaking down sales performance by acquisition channel and customer lifecycle status.
* **Aggregated Financial Summaries:** Utilized built-in Pivot summary engines (`Sum of Sales`) to evaluate top-performing revenue streams.
* **Interactive Filtering Design:** Integrated PivotTable Slicers to dynamically filter operational data views across promotional vectors.
